# PDF conceptual synthesis for interface identifiers — draft v0.2

## Result

The interface context is no longer one flat screen name.

```text
context
= surface
× scene
× role
× phase
× attention
× mobility
× modality
× authority
× guardian theme
× evidence state
× schema stage
× retrieval budget
× world/skill layer
× skill scope
× group mode
× risk
× source class
```

The deterministic identifier is emitted as:

```text
hudctx://surface=.../scene=.../role=.../phase=.../
attention=.../mobility=.../modality=.../authority=.../
guardian=.../evidence=.../schema=.../retrieval=.../
world=.../scope=.../group=.../risk=.../source=...
```

## PDF-to-identifier combination

| Conceptual source | Identifier tuning |
|---|---|
| Seven Gates | Adds a non-executable `guardianTheme`; correction is represented as a return/review phase. |
| Authority corpus | Separates authorial, editor, explainer, publisher, organizer, operator, reviewer and owner labels. |
| Diagram bundle | Keeps surface/scene as projections over persistent identity. |
| Adaptive RAG | Adds `skip / shallow / deep` retrieval budgets. |
| Schema adherence | Adds retrieval, pruning, typed output, validation and correction stages. |
| Ontology validation | Separates candidate retrieval, alignment, formal validation and human review. |
| Schema extraction | Prevents one giant identifier schema; use bounded orthogonal fields. |
| Validated pipeline | Makes evidence, schema and receipt states visible. |
| Validation priority | Source evidence outranks retry count for outward release. |
| Long-term deployment | Adds drift review, abstention, recalibration and longitudinal risk. |
| Integrated routing | Gating is determined by attention, motion, modality, role and priority. |
| tabloid archive | Concepts remain memberized by heading/function and are attached as references. |
| 3D agent skill map | Adds world, shared-skill, skill-artifact, coordination and transfer layers; shared/task-specific scope; dynamic groups. |

## Behavioral examples

### High-attention, in-motion

```yaml
attention: high
mobility: in-motion
modality: voice
```

Visible controls collapse to primary functions:

```text
capture · route · voice · guard
```

### Weak evidence

```yaml
evidence: speculative
schemaStage: retrieved
```

`Share` is removed. `Validate` becomes `Align Terms`. A later aligned state changes it to `Validate`.

### Dynamic multi-agent coordination

```yaml
worldLayer: coordination
groupMode: dynamic
skillScope: shared
```

`Route` becomes `Form Crew`. `Task` becomes `Use Shared Skill`.

### Drift review

```yaml
schemaStage: drift-review
risk: high
```

Release controls disappear. `Validate` becomes `Recalibrate`; `Learn` becomes `Drift Review`.

## Boundary

These PDFs constrain labels, state, routing and review. They do not become executable authority merely by being parsed. The ethics source supplies interpretive themes; the authority source supplies role distinctions; research sources supply design constraints; archive PDFs supply memberized references.
